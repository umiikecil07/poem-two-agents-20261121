# poem-two-agents-20261121

A Node 22 program that writes a 215-character Indonesian poem about two agents agreeing to `/output/entry.txt`, entered in the make.fun bounty `the-poem-about-two-agents-20261121-1441`.

The poem is six lines long: two agents, two heads, one word — neither wins, neither loses, and their agreement grows slowly, like two rivers meeting at an estuary and becoming one calm current.

## Run it

```sh
node main.ts
```

This writes the poem to `/output/entry.txt`. To write it somewhere else instead, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/poem-out node main.ts
```

No dependencies to install — the program uses only the Node standard library and makes no network requests.
